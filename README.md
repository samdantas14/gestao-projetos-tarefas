
 Gestão de Projetos e Tarefas

Sistema web desenvolvido com Django para gerenciar projetos e suas respectivas tarefas.

Tecnologias
- Python
- Django
- SQLite
- Git e GitHub

Como executar

Instale o Django:

    python -m pip install django

Aplique as migrações:

    python manage.py migrate

Inicie o servidor:

    python manage.py runserver

Objetivo
Projeto acadêmico desenvolvido durante a Sprint Relâmpago de Desenvolvimento de Sistemas Web.
